# BRN Express

Site institucional da BRN Express Transporte & Logistica, desenvolvido em Next.js para deploy na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Build

```bash
npm run build
```

## Vercel

- Framework Preset: `Next.js`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: deixe vazio
- Root Directory: deixe vazio ou `.`
